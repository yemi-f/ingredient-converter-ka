A browser-based tool that converts volume measurements (cups, tablespoons, ml, etc.) to grams for specific ingredients, using density data from [King Arthur Baking](https://www.kingarthurbaking.com/learn/ingredient-weight-chart).

### Data source
https://www.kingarthurbaking.com/learn/ingredient-weight-chart

### Supported units
cup, tablespoon, teaspoon, ml, l, floz, pint, quart

### Usage
Open `index.html` in a browser
